# **App Name**: Ghian: Decision Support

## Core Features:

- Authentication: User authentication using Email/Password, Apple, and Google.
- Workspace: A workspace to invite team members and make collaborative decisions.
- Decision Log: Log decisions with title, context, options, rationale, and tags.
- AI Bias Check: Use a tool to scan decision descriptions for cognitive biases and suggest mitigation.
- Voice Reflection: Record audio reflections, upload, transcribe using voice-to-text, and store transcripts.
- Mental Energy Tracker: Track mental energy with a quick daily rating and notes, displayed in charts.
- Team Collaboration: Team collaboration with shared workspaces and push notifications.
- Bias Scanner: Add a Decision detail action ‘Scan for Bias’ that calls a Cloud Function and writes results to Firestore.
- Decision Framer: Create a 4‑step wizard to structure decisions before saving.
- Mental Energy Tracker: Implement quick daily input and charts; show latest score when creating a decision.
- Intuition Compass: Capture and visualize intuition vs. evidence, plus a short AI reflection.
- Red Team Challenge: Enable structured critique from teammates or an AI “red team”.
- Pre-Mortem Risk Tool: Run a pre-mortem session per decision and store a lightweight risk register.

## Style Guidelines:

- Primary color: HSL(210, 65%, 50%) – a vibrant, professional blue that conveys trust and clarity. Hex: #3498DB
- Background color: HSL(210, 20%, 95%) – a very light blue-tinted grey. Hex: #F0F8FF. This creates a clean, modern backdrop.
- Accent color: HSL(180, 50%, 40%) – a calm turquoise that suggests balance and complements the blue tones. Hex: #4ECDC4. Used for highlighting key UI elements and calls to action.
- Headline font: 'Space Grotesk', a sans-serif font providing a computerized, techy feel; suitable for headlines.
- Body font: 'Inter', a sans-serif font that has a neutral, modern apperance, suitable for body text.
- Use clean, modern icons to represent decision categories and actions.
- Maintain a clean and structured layout with clear visual hierarchy.
